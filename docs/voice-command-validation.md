# 단축번호 음성 명령 검증 (#60)

- 요구사항: FR-027, UX-012, NFR-008, NFR-011
- 관련 시나리오: SC-004의 실행 전 단축번호 선택
- 범위: 홈에서 브라우저 음성 인식으로 활성 단축번호를 찾고, 사용자 확인 후 기존 실행 전 확인 화면으로 이동한다.

## 지원 문장과 매칭 기준

| 대표 문장 | 서버 업무 종류 | 추가 조건 |
| --- | --- | --- |
| 아들에게 돈 보내 줘 | TRANSFER | 연결 계좌의 관계가 아들 |
| 딸에게 돈 보내 줘 | TRANSFER | 연결 계좌의 관계가 딸 |
| 연금 확인해 줘 | PENSION_CHECK | 없음 |
| 관리비 확인해 줘 | MANAGEMENT_FEE_CHECK | 없음 |
| 잔액 알려 줘 | BALANCE_CHECK | 없음 |
| 거래 내역 보여 줘 | TRANSACTION_HISTORY | 없음 |
| 고객센터 전화해 줘 | CUSTOMER_CENTER | 없음 |
| 공과금 확인해 줘 | UTILITY_BILL_CHECK | 없음 |

- 공백, 일반적인 마침표·쉼표·물음표·느낌표, 전각 표기를 정규화한다.
- 송금은 `에게/한테`, `돈 보내/송금/이체`, `줘/주세요/줄래/줄래요` 변형을 허용한다.
- 조회는 `확인/조회/알려/보여`, 거래 내역은 `입출금 내역` 변형을 허용한다. 정확한 허용 범위는 `frontend/src/features/voice/shortcutCommands.js`의 전체 문장 규칙을 따른다.
- 패턴 제목이나 고정 번호를 사용하지 않는다. 같은 조건에 맞는 활성 패턴이 여러 개면 사용자가 화면에서 선택한다.
- 미지원·부정·복합 문장을 부분 키워드만으로 실행 대상으로 해석하지 않는다.
- 최종 인식 문장은 매칭 호출에서만 사용하며 앱 상태, 브라우저 저장소, Backend, 로그에 저장하지 않는다. 브라우저의 음성 인식 서비스로 음성이 전송될 수 있다는 안내를 홈에 표시한다.

## 자동 검증

```powershell
cd frontend
npm test
npm run build
```

- 대표 문장 8개, 정규화, 번호·제목 변경, 비활성 대상, 없음·복수 일치
- 시작·말하기 완료·취소, 중간 결과 무시, 취소·화면 이탈 후 늦은 이벤트 무시
- 권한 거부·미지원·마이크 없음·인식 서비스 실패와 재시도
- 기존 실행·방문 로그 및 송금 회귀 테스트

2026-09-06 검증: Node 테스트 42개와 프론트엔드 빌드 통과. Chrome의 390×844 화면에서 보통·큰 글씨 각각 단일·없음·복수 일치, 강조 페이지 이동, 확인·취소, 권한 거부 후 수동 선택, 늦은 결과 무시를 확인했다. 브라우저 검증은 API와 음성 인식 이벤트를 대체했으며, 확인 단계까지 실행·방문·송금 요청이 없고 인식 문장이 요청 본문·브라우저 저장소에 남지 않는 것도 확인했다.

## 실제 브라우저 확인 순서

1. 로그인한 시드 사용자로 홈을 열고 지원 문장을 확인한다.
2. 음성으로 말하기를 누르고 마이크 권한을 허용한다. 대표 문장을 하나씩 직접 말한다.
3. 정확히 하나가 맞으면 해당 페이지·번호만 강조되고 `업무 확인하기`가 표시되는지 확인한다.
4. `업무 확인하기`를 눌러 수취인과 설명을 확인한다. 이때 실행·방문·송금 요청이 없어야 한다. 취소하면 홈에서 계속 사용할 수 있어야 한다.
5. 기존 `시작하기`를 눌렀을 때만 SC-004의 실행 흐름이 시작되는지 확인한다.
6. 지원 문장이 아닌 말과 동일 업무의 복수 패턴으로 각각 없음·복수 안내를 확인한다.
7. 마이크 권한 거부, 인식 중 완료·취소, 다른 메뉴 이동을 확인한다. 이후에도 수동 선택이 가능해야 한다.
8. 390px 화면의 보통·큰 글씨에서 안내, 강조 카드, 확인 버튼, 하단 메뉴를 확인한다. 내용이 길면 본문을 스크롤할 수 있어야 한다.

자동 테스트의 음성 이벤트는 테스트 대역이다. 실제 마이크 발화와 브라우저 인식 서비스의 성공 여부는 위 수동 순서로 별도 확인한다.

2026-09-06 사용자 수동 확인: Chrome에서 실제 발화 인식이 정상 동작함을 확인했다. Brave에서는 음성 인식 서비스 연결 실패(`network`) 안내가 표시됐다. 이번 실제 발화 검증 브라우저는 Chrome이며, Brave에서의 정상 인식은 검증되지 않았다.
