# 접근성 및 안내창 확인

2026-09-07 실제 App·SettingsView·FocusModeCard·VoiceGuideBar를 격리 확인 화면에서 점검했습니다.
외부 음성 API는 실패 응답으로 대체했으며 실제 음질은 이 검증에 포함하지 않습니다.

- 390×844에서 SMALL 제목 24.7px, LARGE 제목 29.9px로 글꼴만 바뀜
- 버튼 최소 높이 48px 유지, 기존 60px 다음 버튼도 60px 유지
- 350자 이상 안내문을 접으면 안내 영역이 약 338px에서 203px로 줄고 다음 버튼 접근 가능
- 접은 상태에도 현재 자막과 재생·펼치기 버튼 유지, 접기는 재생 정지와 별도 동작
- 320×568 LARGE에서 긴 시작 모달의 취소·시작 버튼 모두 화면 안에 위치(하단 528px)
- 모달 내용은 스크롤하고 실행 버튼은 하단에 유지, 가로 넘침 없음
- 설정에서 글씨 미리보기와 음성 속도 선택, 선택 상태의 접근성 속성 확인
- TTS 실패 안내가 보여도 설정 저장 가능, 저장 성공 후 글자 크기 반영

프론트 62개 회귀 테스트와 빌드, 백엔드 TTS 테스트와 WAR 빌드가 통과했습니다.
실기기의 터치·마이크·Marin 음질은 [가족 음성 검증](family-voice-validation.md)에 따라 사람이 확인합니다.
