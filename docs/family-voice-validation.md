# 가족 음성 및 편집 검증

## 자동 확인 범위

- 시작/단계별 문구·음성 방식 저장, 대상 간 독립성, 문구 변경 시 녹음 불일치 표시
- 파일 용량·형식, 소유권, 업로드 실패와 DB 롤백 시 기존 파일 보존
- multipart 업로드, 권한 거절 후 재시도, 녹음 데이터 수집과 마이크 트랙 해제
- 가족 음성 속도 적용과 재생 실패 시 같은 문구의 TTS 전환
- 패턴 생성 후 녹음 업로드 실패를 재시도해도 패턴을 중복 생성하지 않음

`frontend`에서 `npm test`, `backend`에서 `./gradlew test war`로 실행합니다.
DB 통합 테스트는 V6까지 적용한 격리 DB 연결과 `DANJJAK_DB_INTEGRATION_TEST=true`가 필요합니다.
자동 녹음 테스트는 브라우저 API 대역을 사용하므로 실제 마이크·음질 검증을 대신하지 않습니다.

## 사람이 확인할 항목

V6를 적용하고 새 WAR와 프론트를 실행한 뒤 기존 카카오 시연 계정으로 로그인합니다.
Tomcat에는 기존 `OPENAI_API_KEY` 설정을 유지합니다. 로컬 녹음은 `localhost`에서 열고,
다른 기기로 접속할 경우 HTTPS 환경이 필요합니다.

1. 패턴 수정에서 시작 안내를 가족 음성으로 선택합니다. 권한 설명을 읽고 녹음 시작을 누릅니다.
   마이크를 허용하고 대본을 읽은 뒤 마칩니다. 저장 전 미리듣기와 다시 녹음을 확인합니다.
2. 단계 하나에 다른 문구와 녹음을 설정합니다. 최종 확인의 음성 선택과 새 녹음 표시를 확인하고
   저장합니다. 새로고침 후 시작 안내와 해당 단계가 각각 유지되는지 확인합니다.
3. 홈의 시작 확인창과 실제 단계에서 올바른 가족 녹음이 재생되는지 확인합니다. 각 화면의
   자막은 저장한 문구와 같아야 합니다. 느리게/보통/빠르게 설정도 들어봅니다.
4. 단독 단계 편집에서 문구만 변경합니다. 이전 녹음이 유지되고 불일치 표시가 남아야 합니다.
   다시 녹음해 저장하면 표시가 해제되고 새 음성이 재생되어야 합니다.
5. 전체 설정과 다른 방식을 한 단계에 지정한 뒤 전체 설정을 바꿉니다. 명시적으로 선택한
   단계는 그대로여야 하며, 전체 설정 따르기를 고른 단계만 변경되어야 합니다.
6. 녹음이 없는 가족 음성 설정과 재생할 수 없는 녹음을 확인합니다. TTS 전환 이유와 자막이
   보여야 하고 금융 업무 버튼을 계속 사용할 수 있어야 합니다. Marin의 한국어 발음·속도도 확인합니다.
7. 권한 거절, 마이크 분리, 녹음 중 취소, 편집 화면 이탈을 확인합니다. 오류나 취소 후
   마이크 사용 표시가 꺼지고, 기존 저장된 음성은 유지되어야 합니다.
8. 새 패턴의 최종 저장 중 업로드 연결을 끊었다가 복구합니다. 부분 저장 안내와 남은 초안이
   유지되고, 다시 저장한 뒤 같은 단축번호에 패턴이 하나만 존재해야 합니다.

미리듣기·편집·녹음만으로 금융 실행 및 이용 분석 기록이 증가하면 안 됩니다.
